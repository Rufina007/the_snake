# Змейка

Классическая игра «Змейка» на Python и Pygame. Змейка ползёт по полю, ест яблоки и растёт. Если она врезается в собственный хвост, игра начинается заново.

## Правила

- Направление движения меняется стрелками на клавиатуре.
- Каждое съеденное яблоко увеличивает длину змейки на один сегмент. Новое яблоко появляется в случайной свободной клетке.
- Стены не ограничивают поле: уйдя за край, змейка появляется с противоположной стороны.
- Развернуться на 180° нельзя: змейка не может сразу поползти в обратную сторону.
- При столкновении с собственным телом змейка возвращается в начальное состояние: длина 1, центр поля, случайное направление.

## Устройство кода

Игра написана в объектно-ориентированном стиле:

- `GameObject`: базовый класс игрового объекта с позицией, цветом и методом отрисовки;
- `Apple`: наследник, выбирает случайную позицию, не занятую змейкой;
- `Snake`: наследник, хранит сегменты тела, отвечает за движение, смену направления, рост и сброс;
- `handle_keys()`: обработка нажатий клавиш;
- `main()`: игровой цикл: обработка событий, движение, проверка столкновений, отрисовка.

Поле 640×480 пикселей разбито на клетки 20×20, скорость составляет 20 кадров в секунду.

## Стек технологий

- Python 3.9–3.12
- Pygame 2.5
- pytest
- flake8, flake8-docstrings, pep8-naming

## Как запустить

Клонировать репозиторий и перейти в него:

```bash
git clone git@github.com:Rufina007/the_snake.git
cd the_snake
```

Создать и активировать виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate        # Linux / macOS
source venv/Scripts/activate    # Windows
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить игру:

```bash
python the_snake.py
```

## Выводы

- Наследование от общего `GameObject` убирает дублирование: у яблока и змейки общая логика позиции и отрисовки.
- Направление меняется через промежуточное поле `next_direction`. Поэтому два быстрых нажатия за один кадр не дают змейке развернуться внутрь себя.
- Код проверяется линтерами со стандартами PEP 8 и PEP 257 (docstrings).
